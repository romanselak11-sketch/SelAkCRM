# Acceptance Matrix

Проверки выполняются после миграции данных или перед релизом.

| Сценарий | Ожидаемый результат |
|---|---|
| Setup или login | Успешный вход в систему, токен сессии выдаётся |
| Главная страница | Задачи продления и уведомления загружаются без ошибок |
| Клиенты | Поиск, создание, редактирование и просмотр работают корректно |
| Полисы | Список, пагинация, создание и редактирование доступны согласно ролям |
| Задачи | Реестр задач продления открывается и фильтруется |
| Аналитика | График и сводка загружаются; для MANAGER доступ ограничен (403) |
| Настройки | Переключение темы light/dark сохраняется |
| Desktop запуск | Приложение стартует, база хранится в пользовательском каталоге |
